# MCP 2026-07-28 Streamable HTTP contract

All agent → gateway MCP calls MUST be independent HTTP POSTs. No `Mcp-Session-Id`. No sticky `initialize`.

## Headers (required on every request)

| Header | Example | Role |
|--------|---------|------|
| `Content-Type` | `application/json` | JSON-RPC body |
| `Mcp-Protocol-Version` | `2026-07-28` | Protocol |
| `Mcp-Method` | `tools/call` | L7 routing + CEL (must match JSON-RPC `method`) |
| `Mcp-Name` | `transfer_funds` | L7 routing + CEL (must match tool name for `tools/call`) |

Gateway CEL (coarse policy, not identity):

- Allow `mcp.tool.name == "transfer_funds"` for list/call as configured.
- Require `Mcp-Method` and `Mcp-Name` present and consistent with the body.

## JSON-RPC body

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "method": "tools/call",
  "params": {
    "name": "transfer_funds",
    "arguments": { }
  },
  "_meta": {
    "protocolVersion": "2026-07-28",
    "clientInfo": { "name": "banking-fund-transfer-demo", "version": "0.1.0" },
    "clientCapabilities": {}
  }
}
```

`arguments` MUST conform to the route’s input schema (strict vs legacy).

## Routes (agentgateway :8080)

| Path | Upstream | Schema |
|------|----------|--------|
| `/v1/chat/completions` | LM Studio `http://127.0.0.1:1234/v1` | OpenAI Chat Completions |
| `/mcp/strict` | FastMCP `http://127.0.0.1:8001/mcp` | `transfer_funds.strict.schema.json` |
| `/mcp/legacy` | FastMCP `http://127.0.0.1:8002/mcp` | `transfer_funds.legacy.schema.json` |

MCP backends: `statefulMode: stateless`.

## Errors

| Route | Illegal business payload | JSON-RPC | Recorded? | Repair? |
|-------|--------------------------|----------|-----------|---------|
| strict | Schema fail at gateway | `-32602` | no | yes (bounded) |
| legacy | Weak schema admits; tool refuses | opaque / non-`-32602` | no | no |

## Comparison CLI

```text
python -m agent.compare --contract {legacy|strict|both} [--prompt FILE]
```

Missing/invalid `--contract` → fail fast. Do not read contract mode from the environment.
